# Inventario

Programa de C++ para consultar un catalogo y modificar un inventario guardado
en archivos CSV.

## Archivos

- `main.cpp`: carga el catalogo, muestra opciones y actualiza el inventario.
- `catalogo_minecraft_100_es.csv`: datos del catalogo.
- `inventario.csv`: datos guardados del inventario.

## Compilar y ejecutar

Desde esta carpeta:

```bash
g++ main.cpp -o inventario
./inventario
```
