# Snake con listas

Ejemplo de Snake con SFML. El cuerpo usa una lista doble y los colores de la
comida avanzan usando una lista circular.

## Requisitos

Se necesita `g++` y SFML 2.x.

## Compilar y ejecutar

Desde esta carpeta:

```bash
g++ proyect.cpp -o snake -lsfml-graphics -lsfml-window -lsfml-system
./snake
```
