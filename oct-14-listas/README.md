# Ejercicios de listas, pilas y colas

Ejemplos de estructuras enlazadas y ejercicios para practicar sus
operaciones. Cada archivo `.cpp` es un programa separado.

## Archivos

- `main.cpp`, `pila.cpp` y `cola.cpp`: ejemplos de estructuras basicas.
- `ejercicio1.cpp` a `ejercicio4.cpp`: galeria de fotos, mesa de cartas,
  pila y cola de solicitudes.

Compila solo el archivo que quieras probar. Por ejemplo:

```bash
g++ ejercicio1.cpp -o ejercicio1
./ejercicio1
```
