# Movimiento con SFML

Ejemplo de movimiento separado en funciones para procesar la entrada,
actualizar la posicion y dibujar el objeto.

## Requisitos

Se necesita `g++` y SFML 2.x.

## Compilar y ejecutar

Desde esta carpeta:

```bash
g++ movimiento_separado.cpp -o movimiento -lsfml-graphics -lsfml-window -lsfml-system
./movimiento
```
