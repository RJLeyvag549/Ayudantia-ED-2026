# Simulacion de particulas

Compara operaciones de un motor de particulas implementado con `vector` y
`list`.

## Archivos

- `ArrayEngine.h` y `ListEngine.h`: operaciones para cada estructura.
- `Particle.h`: datos de una particula.
- `main.cpp`: mide los tiempos de las pruebas.

## Compilar y ejecutar

Desde esta carpeta:

```bash
make
./benchmark_fisicas
```

Para borrar el ejecutable generado:

```bash
make clean
```
