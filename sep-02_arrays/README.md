# Datos y arreglos

Programa que carga datos de Pokemon desde un CSV, muestra resumenes y aplica
filtros.

## Archivos

- `main.cpp`: lectura y procesamiento de los datos.
- `Pokemon_stats.csv`: datos de entrada.
- `pokemon_legendarios.csv`: archivo de salida con los registros filtrados.

## Ejecutar

Desde esta carpeta, compila y ejecuta el programa para que encuentre el CSV:

```bash
g++ main.cpp -o pokedex
./pokedex
```
