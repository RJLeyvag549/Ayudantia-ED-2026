# Material de Estructuras de Datos

Ejercicios y ejemplos en C++ usados como apoyo para el curso.

## Carpetas

- `agos-*` y `sep-*`: tipos de datos, arreglos, matrices y listas.
- `oct-*`: listas, pilas, colas y grafos.
- `nov-*`: ejemplos graficos con SFML.
- `Tarea_1A` y `Tarea_2`: tareas de inventario y simulacion de particulas.
- `proyecto`: ejemplo interactivo con SFML.

## Programas en esta carpeta

- `fabricar_tren.cpp`: uso de una lista enlazada para representar vagones.
- `pacman.cpp`: juego con SFML, grafos y otras estructuras.
- `proyecto.cpp`: ejemplo de juego con SFML y fisica.

Los programas de la carpeta principal son independientes. Revisa el README
de cada carpeta para ver como compilar sus ejemplos.
