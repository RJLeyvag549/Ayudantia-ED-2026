# Arreglos y matrices

Esta carpeta contiene ejemplos de arreglos estaticos y dinamicos, `vector`,
matrices y multiplicacion de matrices.

## Archivos

- `clase3.cpp`: arreglos, vectores, estructuras y matrices.
- `main.cpp`: ejemplos y mediciones de operaciones con arreglos y matrices.
- `matrices.cpp`: comparacion de algoritmos para multiplicar matrices.

Cada archivo tiene su propio `main`; compila y ejecuta uno a la vez. Por
ejemplo:

```bash
g++ clase3.cpp -o clase3
./clase3
```
